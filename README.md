# MotorAI — AI-помощник по анализу заездов в Assetto Corsa

Пост-сессионный анализатор телеметрии для Assetto Corsa (оригинал). Записывает
твои круги, строит теоретический идеальный круг (склейка лучших отрезков
трассы из всех валидных попыток), находит повороты, где ты теряешь время
относительно этого идеала, и выдаёт конкретные текстовые советы
(точка торможения, скорость в апексе, момент открытия газа).

## Архитектура

```
motorai/
  capture/      # чтение Shared Memory AC (Windows-only, работает только при запущенной игре)
  storage/      # сохранение записанных кругов на диск (Parquet + session metadata)
  analysis/     # resample по дистанции, теоретический идеальный круг, детекция поворотов, советы
  sample_data/  # генератор синтетических кругов — для разработки и тестов без Windows/AC
  ui/            # десктопное приложение (PySide6) — отчёт по сессии
  report/        # экспорт отчёта в самодостаточный HTML
scripts/
  build_exe.ps1  # сборка .exe через PyInstaller (запускать на Windows)
docs/
  WINDOWS_SETUP.md
```

Модуль `capture` — единственная Windows-специфичная часть (читает память
процесса `acs.exe` через `acpmf_physics` / `acpmf_graphics` / `acpmf_static`).
Всё остальное (`analysis`, `ui`, `report`) кроссплатформенно и покрыто тестами
на синтетических данных из `sample_data`.

## Быстрый старт (разработка, без Windows)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest tests/
python -m motorai.ui.app --demo   # открыть UI на синтетической сессии
```

## Быстрый старт (реальный заезд, Windows)

Скопируй проект на Windows-ПК и запусти `build.bat` — он поставит всё
нужное и соберёт четыре готовых `.exe` (калибровка, запись, просмотр,
экспорт в HTML), дальше Python не нужен. Подробности и порядок действий —
в `docs/WINDOWS_SETUP.md`.

## Статус

MVP: запись сессии → анализ → отчёт. Без live-подсказок во время заезда
(осознанное решение — на треке важна латентность, а не текст).
