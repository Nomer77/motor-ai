# MotorAI

Пост-сессионный анализатор телеметрии Assetto Corsa — см.
`.claude/PROJECT_STRUCTURE.md` для полного описания архитектуры, дерева
проекта, потока данных и известных рисков/пробелов.

## Правило: обновляй документацию при каждой правке

**После любой значимой правки кода (новая фича, рефакторинг, исправление
бага) — обнови `.claude/PROJECT_STRUCTURE.md`**, чтобы он отражал текущее
состояние: дерево файлов, что где лежит, что изменилось в потоке данных,
актуальный список известных пробелов/рисков. Это единственный способ,
которым следующая сессия (другой контекст, другой день, другой человек)
поймёт, что уже сделано и что нет — личная память модели сюда не
переносится.

Перед тем как начинать новую правку — сначала прочитай
`.claude/PROJECT_STRUCTURE.md`, чтобы не терять контекст.

## Быстрые команды

```bash
source .venv/bin/activate
python -m pytest tests/ -q                       # ядро анализа, кроссплатформенно
python -m motorai.ui.app --demo                   # UI на синтетических данных
python -m motorai.report --demo --out /tmp/r.html # HTML-отчёт на синтетических данных
```

Разработка идёт на macOS — `motorai/capture/` (чтение AC Shared Memory)
нельзя запустить и протестировать локально, только на Windows с
установленной игрой. Всё остальное (`analysis/`, `ui/`, `report/`)
кроссплатформенно и покрыто тестами на синтетических данных из
`sample_data/synth.py`.
